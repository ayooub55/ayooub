# 🟢 L-QISM 1 — **3.2. LE MICROSCOPE ÉLECTRONIQUE À BALAYAGE (MEB)**

*(Had l-qism ja mn b3d l-MET f l-partie I)*

## 🔴 Chno howa l-MEB b kelma wa7da?

**L-MET** kay-dir **l-électrons y-djouz mn l-coupe** → t-chouf **l-dakhel** dyal l-cellule (2D).

⭐ **L-MEB** kay-dir **l-électrons y-mchmchiw 3la s-sat7** → t-chouf **l-barra / s-sat7** dyal l-7aja (3D).

## ⚡ T-chbiha bach t-fhem

| | L-MET | ⭐ L-MEB |
|---|---|---|
| **T-chbiha** | ⭐ **B7al t-chouf chi 7aja b d-daw mn l-wra** (radiographie) | ⭐ **B7al t-mchi 3la chi 7aja b yeddek w nta m3emmem** (toucher) |
| **Chno t-chouf** | L-**dakhel** (l-organites) | L-**barra** (s-sat7, l-forme) |
| **L-image** | **2D** (plate) | ⭐ **3D** (kayn l-3omq w d-dell) |
| **L-coupe** | ⭐ **Obligatoire** (40-60 nm) | ⭐ **MA KAY-9T3OUCH** — l-3ayna kamla |

## 🔴 Kifach kay-khdem?

1. **Un faisceau d'électrons très fin** kay-**balayé** (= scan) la surface de l'échantillon, ligne par ligne — b7al l-écran dyal l-ancienne télé
2. L'échantillon **doit être CONDUCTEUR** — sinon les électrons s'accumulent (⚠️ « effet de charge »)
3. ➡️ ⭐ **7it hadak : les échantillons BIOLOGIQUES (machî conducteurs) khasshom t-9elleb b CHI TBE3 RQI9 dyal MÉTAL** — usually **l-or** or **l-carbone** — hadi smitha ⭐ **LA MÉTALLISATION**
4. Les électrons **rebondissent** (électrons secondaires / rétrodiffusés) → un détecteur les compte
5. L'ordinateur reconstruit l'image **en 3D**

## 🔴 ⭐ LES CHIFFRES

| | **MET** | ⭐ **MEB** |
|---|---|---|
| **Résolution** | ~**0,1-0,2 nm** ⭐ (l-a7san) | ~**5-10 nm** (a9all) |
| **Grossissement** | **×1 500 → ×600 000** | **×10 → ×500 000** |
| **Image** | **2D**, noir et blanc | ⭐ **3D**, noir et blanc |
| **Ce qu'on voit** | **ULTRASTRUCTURE** (dakhel) | ⭐ **SURFACE / TOPOGRAPHIE** |
| **Préparation** | coupe **40-60 nm** | ⭐ **échantillon entier** + **métallisation** |
| **Profondeur de champ** | faible | ⭐⭐ **TRÈS GRANDE** (hadak 3lach l-image t-ban 3D) |

## 🦷 ⭐⭐ 3LACH L-MEB MOUHIM LIK (médecine dentaire)

Had l-MEB **howa l-asas dyal bzaf dyal l-ba7t f dentaire** :

1. ⭐ **L'ÉMAIL** — t-chouf **les prismes de l'émail**, la forme des **cristaux d'hydroxyapatite**
2. ⭐ **LE MORDANÇAGE ACIDE** — ⭐⭐ hada **l-asas dyal l-adhésion** (composites). L-MEB kay-wrrik kifach l-acide orthophosphorique **37 %** kay-khlli des **microporosités** f l-émail → l-résine t-dkhol fihom → t-creyya **les « tags » de résine** ⭐⭐ **HADA HOWA L-PRINCIPE DYAL L-COMPOSITE — RAH TOMBABLE F L-EXAMEN DYAL MATÉRIAUX**
3. ⭐ **LA JONCTION ÉMAIL-COMPOSITE** — t-chouf l-interface ( infiltration, gaps)
4. ⭐ **LES IMPLANTS DENTAIRES** — la surface dyal l-**titane** (rugosité, sablage, anodisation) → ⭐ **l'ostéointégration** kat-3tamed 3la la topographie dyal s-sat7
5. ⭐ **L'INSTRUMENTATION CANALAIRE** — t-chouf les limes après usage (déformations, fractures)
6. ⭐ **LA PLAQUE BACTÉRIENNE / LE BIOFILM** — ⭐⭐ l-MEB howa **l-mezyan** bach t-chouf les bactéries f l-bouche (l-MET ma kay-wrri-ch s-sat7)

⚠️ **MNÉMOTECHNIQUE :** « **MET = D**akhel (2D) · **MEB = B**arra (3D) » → **D / B** ⭐

# 🟡 L-QISM 3 — **III. MÉTHODES D'ÉTUDE DU FONCTIONNEMENT**
